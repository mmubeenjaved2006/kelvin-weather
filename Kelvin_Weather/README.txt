KELVIN WEATHER STUDIO
=====================
Pure HTML, CSS and JavaScript weather website.

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Search for any city and switch between Kelvin (K), Celsius (°C) and Fahrenheit (°F).

FEATURES
- Real weather via Open-Meteo free APIs, no API key needed
- City search, current conditions, feels-like temperature
- Humidity, wind, precipitation, UV index
- 7-day forecast
- Remembers the last searched city in the same browser
- Responsive charcoal and warm brass design
- Static hosting compatible, including Vercel

NOTE
An internet connection is required to load live weather data and the optional Google Fonts.
Weather readings are provided by Open-Meteo. Kelvin is computed from Celsius by adding 273.15.

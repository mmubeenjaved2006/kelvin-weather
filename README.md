## 📖 About the Project

Kelvin Weather is a responsive weather application designed to provide weather forecasts and temperature conversion in a clean, user-friendly interface.

The project demonstrates frontend development, JavaScript programming, and weather API integration.

## ✨ Key Features

- 🌤️ Weather forecasts
- 🌡️ Temperature conversion
- 📱 Responsive website design
- 💻 Desktop and mobile compatibility
- 🎨 Clean and interactive user interface
- ⚡ Lightweight frontend application

## 💻 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/mmubeenjaved2006/kelvin-weather.git
```

### 2. Open the project

```bash
cd kelvin-weather/Kelvin_Weather
```

### 3. Run the website

Open the project's main HTML file in a web browser.

An internet connection may be required to retrieve live weather information.
